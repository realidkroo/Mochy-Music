# Making modules for Mochy

The module guide moved to the wiki: **[realidkroo.github.io/Mochy-Music/docs/wiki](https://realidkroo.github.io/Mochy-Music/docs/wiki/#modules-types)**.

It covers everything that used to be here, and more:

- [What a module is and how it works](https://realidkroo.github.io/Mochy-Music/docs/wiki/#modules-types), and [your first one in two minutes](https://realidkroo.github.io/Mochy-Music/docs/wiki/#modules-first)
- [Publishing on GitHub](https://realidkroo.github.io/Mochy-Music/docs/wiki/#modules-github): attach a zip with `mochyymodule` in its name to a release, and people add it by pasting your project's link
- [Your own player](https://realidkroo.github.io/Mochy-Music/docs/wiki/#modules-player): blocks, backgrounds, animation, a visualizer, style sheets, a customise sheet, buttons, the chevron menu and shader code
- Looks, fonts, pages, menu rows and liquid glass
- Web modules, zip modules and JS Modules scripts
- Sharing, testing, troubleshooting, and the [notes for Mochy developers](https://realidkroo.github.io/Mochy-Music/docs/wiki/#devs)

The wiki's source is [`docs/wiki/index.html`](../docs/wiki/index.html). Change it in the same commit as anything that changes what a module can do.

The catalog people see under **Add a module** is [`catalog.json`](catalog.json) in this folder.
