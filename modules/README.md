# Making modules for Mochy

The module guide moved to the wiki: **[realidkroo.github.io/Mochy-Music/wiki](https://realidkroo.github.io/Mochy-Music/wiki/#modules-types)**.

It covers everything that used to be here, and more:

- [What a module is and how it works](https://realidkroo.github.io/Mochy-Music/wiki/#modules-types), and [your first one in two minutes](https://realidkroo.github.io/Mochy-Music/wiki/#modules-first)
- [Publishing on GitHub](https://realidkroo.github.io/Mochy-Music/wiki/#modules-github): attach a zip with `mochyymodule` in its name to a release, and people add it by pasting your project's link
- [File structure](https://realidkroo.github.io/Mochy-Music/wiki/#modules-files) for every kind of module, and [updates](https://realidkroo.github.io/Mochy-Music/wiki/#modules-install): the update button that shows up when you publish a new release
- [Your own player](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player): blocks, frosted panels, svg paths, blur, backgrounds, [keyframes](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-keyframes), [states and events](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-states), a visualizer, style sheets, a customise sheet, buttons, the chevron menu and shader code
- [Your own bar](https://realidkroo.github.io/Mochy-Music/wiki/#modules-glass) and [your own pages](https://realidkroo.github.io/Mochy-Music/wiki/#modules-pages) in AGSL, with Liquid Glass as the worked example
- Looks and fonts
- [Song sources](https://realidkroo.github.io/Mochy-Music/wiki/#modules-web), [lyrics providers](https://realidkroo.github.io/Mochy-Music/wiki/#modules-lyrics), [song info providers](https://realidkroo.github.io/Mochy-Music/wiki/#modules-metadata), zip modules and JS Modules scripts
- Sharing, testing, troubleshooting, and the [notes for Mochy developers](https://realidkroo.github.io/Mochy-Music/wiki/#devs)

The wiki's source is [`docs/wiki/index.html`](../docs/wiki/index.html). Change it in the same commit as anything that changes what a module can do.

The catalog people see under **Add a module** is [`catalog.json`](catalog.json) in this folder.
