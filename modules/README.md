# Making modules for Mochy

The module guide moved to the wiki: **[realidkroo.github.io/Mochy-Music/wiki](https://realidkroo.github.io/Mochy-Music/wiki/#modules-types)**.

It covers everything that used to be here, and more:

- [What a module is and how it works](https://realidkroo.github.io/Mochy-Music/wiki/#modules-types), [stacked looks &amp; priority](https://realidkroo.github.io/Mochy-Music/wiki/#modules-how), and [your first one in two minutes](https://realidkroo.github.io/Mochy-Music/wiki/#modules-first)
- [Publishing on GitHub](https://realidkroo.github.io/Mochy-Music/wiki/#modules-github): attach a zip with `mochyymodule` in its name to a release, and people add it by pasting your project's link
- [File structure](https://realidkroo.github.io/Mochy-Music/wiki/#modules-files) for every kind of module, [manifest.json](https://realidkroo.github.io/Mochy-Music/wiki/#modules-manifest), and [adding &amp; updating](https://realidkroo.github.io/Mochy-Music/wiki/#modules-install)
- [Looks](https://realidkroo.github.io/Mochy-Music/wiki/#modules-look), [fonts](https://realidkroo.github.io/Mochy-Music/wiki/#modules-fonts), and [Android versions &amp; GPU fallback](https://realidkroo.github.io/Mochy-Music/wiki/#modules-compat) (AGSL → GLES 3.0 &amp; Dual-Kawase on Android 7–12)
- [Your own player](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player): blocks, frosted panels &amp; blur, svg paths, backgrounds, [keyframes](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-keyframes), [states and events](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-states), [lyrics your way (`flow`, `custom`, `mochy`)](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-lyrics), [custom sheets, lyrics &amp; queue pages](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-sheets), [live surfaces](https://realidkroo.github.io/Mochy-Music/wiki/#modules-player-surface), shader code, and your own editor
- [Full interface replacement](https://realidkroo.github.io/Mochy-Music/wiki/#modules-recreate-app): [your own glass](https://realidkroo.github.io/Mochy-Music/wiki/#modules-glass), [nav bar](https://realidkroo.github.io/Mochy-Music/wiki/#modules-navbar), [mini player](https://realidkroo.github.io/Mochy-Music/wiki/#modules-mini), [custom pages](https://realidkroo.github.io/Mochy-Music/wiki/#modules-pages), [live media blocks](https://realidkroo.github.io/Mochy-Music/wiki/#modules-page-blocks), [custom Settings pages](https://realidkroo.github.io/Mochy-Music/wiki/#modules-custom-settings), [taking over pages](https://realidkroo.github.io/Mochy-Music/wiki/#modules-takeover), [every caller](https://realidkroo.github.io/Mochy-Music/wiki/#modules-callers), [floating lyrics &amp; app backgrounds](https://realidkroo.github.io/Mochy-Music/wiki/#modules-floating), and [bubble menus &amp; native sheets](https://realidkroo.github.io/Mochy-Music/wiki/#modules-bubble-and-sheets)
- [Song sources](https://realidkroo.github.io/Mochy-Music/wiki/#modules-web), [lyrics providers](https://realidkroo.github.io/Mochy-Music/wiki/#modules-lyrics), [song info providers](https://realidkroo.github.io/Mochy-Music/wiki/#modules-metadata), [audio effects (LiveProg `.eel` &amp; native `mochy_fx.h`)](https://realidkroo.github.io/Mochy-Music/wiki/#modules-audio), [zip modules](https://realidkroo.github.io/Mochy-Music/wiki/#modules-zip), and [JS Modules scripts](https://realidkroo.github.io/Mochy-Music/wiki/#modules-js)
- [Sharing](https://realidkroo.github.io/Mochy-Music/wiki/#modules-share), [testing](https://realidkroo.github.io/Mochy-Music/wiki/#modules-test), [troubleshooting](https://realidkroo.github.io/Mochy-Music/wiki/#modules-trouble), [security &amp; sandbox](https://realidkroo.github.io/Mochy-Music/wiki/#modules-sandbox), and the [notes for Mochy developers](https://realidkroo.github.io/Mochy-Music/wiki/#devs)

The wiki's source is [`docs/wiki/index.html`](../docs/wiki/index.html). Change it in the same commit as anything that changes what a module can do.

The catalog people see under **Add a module** is [`catalog.json`](catalog.json) in this folder.
