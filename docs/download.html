What is a nightly build?

Built automatically from the newest code on the main branch. It has changes that are not in a stable release yet, so you can try new things first.
Each nightly replaces the one before it. Build date and commit are shown above, so you know which code you are running.

Before you install

  • It can have bugs or crash. Features may change or disappear before stable.
  • Make a backup in the app first.
  • Found a bug? Open an issue on GitHub with the build date and commit.
  • Want fewer surprises? Switch back to Stable above.

Install in four steps

  1. Open this page on your phone and download the APK.
  2. Open the downloaded file.
  3. Android asks to allow installs from your browser or file manager. Say yes.
  4. Open Mochy. No account needed to start listening.
Updating works the same way. Install the new APK over the old one and your library stays.

Good to know

Both builds are FOSS builds. They have no self-update permission, so update by installing the new APK.
Android 8 and newer. Android 7 is supported unofficially.
Blur and glass need Android 12. Some effects need Android 13. Older phones get a plain version.
Only download Mochy from the official releases. A random mirror or Telegram link could be a modified app. Official releases
